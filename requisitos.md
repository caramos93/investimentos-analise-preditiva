# Projeto Pessoal Um — Requisitos

Criado em: 13/09/2026

## Objetivo
Criar um projeto pessoal usando inteligência artificial com foco em gerar **experiência prática na ferramenta** (Claude Code / IA aplicada a dados), que sirva de argumento de venda para as empresas onde Caroline aplicar a vagas com esse foco.

## Histórico / motivação
- Caroline tem conhecimento e forte interesse na área de **investimentos financeiros**.
- Quer aprofundar o conhecimento nos tipos de investimento atuais, do **conservador ao mais agressivo**.
- Quer unir esse estudo ao uso da ferramenta para chegar em um **produto final prototipado**.

## Ideia inicial
1. Fluxo de **leitura e tratamento de dados públicos** disponíveis para consumo (dados históricos financeiros e de mercado).
2. **Dashboard** como produto final, construído em conjunto com a IA.
3. **Análises temporais e de previsão** (séries temporais, modelos preditivos) sobre os dados históricos.
4. **Python** como linguagem central — o projeto também serve para treinar Python na prática (análise de dados e previsões).

## Resultado esperado
- Portfólio de projetos pessoais publicável no **GitHub** e divulgável no **LinkedIn**.

## Focos principais
- Python
- SQL / Databricks
- GitHub
- Dados financeiros e de mercado, com foco em investimento
- Análise preditiva

- Esta pasta segue a convenção geral de `Projetos/requisitos.md`.

- Decisões, fórmulas, conceitos de investimento e fontes de dados relevantes devem virar memória.
