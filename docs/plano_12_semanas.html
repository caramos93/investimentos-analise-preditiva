Estudo

Trilha teórica por pilar — tudo gratuito

Pythonbásico → intermediário
Kaggle Learn: Python → Pandas → Time Series. Livro Python for Data Analysis (Wes McKinney, 3ª ed., gratuito em wesmckinney.com/book). Hábito: toda vez que abriria o Excel, tentar no pandas.
SQL / Databricksforte → avançado
Databricks Academy (gratuito): Lakehouse Fundamentals e trilha Data Analyst. Documentação do Free Edition, Delta Lake e window functions.
Power BImanutenção → criação
Microsoft Learn, trilha Power BI Data Analyst (PL-300). SQLBI: DAX Guide e o curso gratuito Introducing DAX. Modelo estrela como base de tudo.
Finançasinteresse → domínio
B3 Educação (cursos gratuitos); site do Tesouro Direto (simuladores e explicação por título); Banco Central, Cidadania Financeira; programa da CPA-10 (ANBIMA) como checklist de conceitos.
Previsãozero → aplicado
Forecasting: Principles and Practice (otexts.com/fpp3, gratuito; exemplos em R, mas a teoria é o que importa). Kaggle Time Series. Documentação de statsmodels e Prophet.
Gitconta → prática
GitHub Skills (skills.github.com) e o livro Pro Git (git-scm.com/book, em português).

Método

Usar a IA sem perder o aprendizado

  1. Pedir explicação antes do código: "me explique como fazer X, depois me mostre".
  2. Escrever a primeira versão sozinha; usar a IA para revisar, apontar erros e sugerir a forma idiomática.
  3. Toda função gerada com IA é reescrita com as próprias palavras nos comentários.
  4. Registrar no diário o que a IA fez que você ainda não saberia fazer — essa lista é a sua pauta de estudo.
